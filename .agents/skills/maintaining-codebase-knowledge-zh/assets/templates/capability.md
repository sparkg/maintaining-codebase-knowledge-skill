# 能力：简短名称

最后验证：相关时记录代码版本和日期

证据快照：记录可定位的代码版本，以及与任务有关的关键符号。如果证据包含未提交文件，或仓库没有使用版本控制，则记录所选文件的完整哈希。只修改文档的提交不能说明检查的是哪一份代码。不要缩写证据哈希，也不要计算整个仓库的哈希。

## 快速了解

先提供足够的信息，帮助开发者判断下一步该读哪里。详细内容链接到后续章节，不要在这里重复。

| 问题 | 简要回答 |
|---|---|
| 这项能力负责什么结果？ | 领域或业务结果 |
| 谁或什么会使用它？ | 主要调用方或使用方 |
| 哪些实现单元包含它？ | 链接架构文档中“能力与实现单元的对应关系”表格 |
| 现有扩展点可以从哪里接入改动？ | 链接已验证的扩展点，或说明尚未发现 |
| 哪些行为必须继续正常工作？ | 链接主要约束及其测试 |
